# UI MultiCam

Ce dossier contient les maquettes HTML de référence validées écran par écran.

Convention :

- un dossier par écran : `NN-nom-ecran/` ;
- `index.html` = maquette visuelle exécutable ;
- `README.md` = spécification UI, fonctionnelle et technique ;
- seules les versions validées servent de référence aux agents de codage.

## Écrans

1. `01-session-discovery` — accueil, découverte LAN, rejoindre ou créer une session.
